## 💡 The Problem
Independent musicians and creators wait **3 to 6 months** to receive their streaming royalties from Spotify, Apple Music, and distributors. When artists need \$5,000 to fund a tour, production, or album launch, they are forced into **predatory label advances** (giving up 80%+ rights) or high-interest debt.

Previous Web3 attempts (like *Royal* and *JKBX*) collapsed because they focused on **speculative NFT collectibles** and suffered from **expensive Ethereum gas fees** where gas costs exceeded the royalty payouts.

---

## ⚡ The LyraX Solution
LyraX removes the NFT speculation and replaces it with a **cash-flow-first Real World Asset (RWA)** financing protocol powered by **AI Underwriting** and **Stellar Soroban**:

1. **AI Catalog Underwriter (The Brain):** Analyzes historical Spotify/Apple Music metrics, monthly listener retention, and decay curves to generate an instant risk grade (A+ to B) and approve a fair USDC cash advance.
2. **Instant Liquidity on Stellar:** Investors fund creator royalty pools with USDC and artists draw advances immediately.
3. **Continuous Micro-Payouts:** As streaming revenue arrives, Stellar’s sub-cent network fees (`< $0.00001`) allow LyraX to distribute micro-dividends to token holders in real-time (daily/weekly) instead of quarterly.

## 🚀 Getting Started

### Prerequisites
* Flutter SDK (>= 3.41.0)
* Dart SDK (>= 3.11.0)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dranyl-23/Lyrax.git
   cd Lyrax
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run on Chrome (Web Access):**
   ```bash
   flutter run -d chrome
   ```

4. **Run on Windows Desktop:**
   ```bash
   flutter run -d windows
   ```

5. **Run on Connected Mobile Device:**
   ```bash
   flutter run
   ```
